# 如何写笔记

文章保存在项目的 `docs` 文件夹中，每个 `.md` 文件对应一个网页。

## 新增一篇笔记

在 `docs/notes` 下创建文件，例如 `first-note.md`：

```md
# 我的第一篇笔记

## 学了什么

用一两句话描述今天的主题。

## 我的理解

用自己的话解释，并给出例子。

## 遇到的问题

记录问题、排查过程和解决方法。

## 参考资料

记录原始资料的链接。
```

## 加入目录

打开 `docs/.vitepress/config.ts`，在学习笔记的 `items` 中加入：

```ts
{ text: '我的第一篇笔记', link: '/notes/first-note' }
```

也可以在[笔记索引](/notes/)里增加文章链接。

## 插入图片

把图片放在文章旁的 `images` 文件夹里，通过相对路径引用：

```md
![实验结果](./images/result.png)
```

## 预览与发布

在项目目录运行 `pnpm docs:dev`，查看本地修改。确认内容后提交并推送到 GitHub，部署成功后网站会自动更新。
