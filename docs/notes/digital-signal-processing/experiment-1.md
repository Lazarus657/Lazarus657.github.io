# 实验1：采样、混叠与ADC量化

> 范围：MATLAB仿真与代码练习。STM32固定数组验证尚未完成。
> 考核结果：85/100，通过MATLAB阶段。

## 1. 目标与流程

理解采样率与时间轴的关系，验证混叠，区分直流偏置、削顶和量化，并编写ADC分析函数。

学习流程：MATLAB基础讲解与小练习 → 预测、运行及记录 → 问答考核 → 独立代码练习 → 评分与补练。前3个实验逐步加入MATLAB基础；代码练习难度随实验提升。

本次操作顺序：

1. 生成带偏置正弦，计算均值、均方根和交流均方根。
2. 每隔一个样本取样，检查时间间隔与实际采样率。
3. 改变采样率，验证7 kHz及6.5 kHz输入的混叠频率。
4. 改变偏置与幅值，区分平移、幅值变化和削顶。
5. 比较12、8、4位量化步长与误差。
6. 编写`analyze_adc`，完成三组测试和输入/重建电压叠加图。

## 2. MATLAB基础要点

### 2.1 时间向量与信号

```matlab
fs = 8000;
N = 256;
t = (0:N-1)' / fs;
x = bias + A*sin(2*pi*fin*t + phi);
```

- `t`为`N×1`列向量；`1/fs`只是采样间隔，`N/fs`只是一个标量。
- 正弦相位使用`2*pi*fin*t`，频率乘时间；不能写成除以频率。
- MATLAB索引从1开始：第`k`个样本对应时间`(k-1)/fs`。
- 时间轴由秒转为毫秒时，只将绘图横坐标乘1000，正弦计算仍使用秒。

### 2.2 数组运算与统计

```matlab
B = sum(x)/numel(x);                    % 均值
C = sqrt(sum(x.^2)/numel(x));           % 原信号RMS
x_ac = x-B;
D = sqrt(sum(x_ac.^2)/numel(x_ac));     % 去均值后的交流RMS
```

`.^`为逐元素求幂；`./`为逐元素相除。`x-B`保留数组尺寸，列向量经`sum`汇总后得到标量。矩阵的`sum`默认按列求和。

本次基础练习参数：幅值0.8、偏置1.2、频率1 kHz、初相位`pi/6`。结果：均值约1.2，原信号RMS约1.3266，交流RMS约0.5657。

### 2.3 索引与每隔一个取样

```matlab
x_sub = x(1:2:end);
t_sub = t(1:2:end);
dt = diff(t_sub);
fs_each = 1 ./ dt;
```

`起点:步长:终点`生成索引序列；`1:2:end`取第1、3、5……个元素，最后一个元素不一定被取到。信号与时间必须使用相同索引。

本例取样后有128个样本，间隔0.00025 s，实际采样率4 kHz。若仍按8 kHz解释，时间被压缩为一半，原1 kHz信号会被误判为2 kHz。

### 2.4 绘图与结构体

```matlab
subplot(3,1,1);                       % 3行1列，选第1个区域
plot(r.t*1000, r.vin, 'o-');
hold on;                             % 保留当前图并叠加
plot(r.t*1000, r.vq, 'x--');
xlim([0 3]);                         % 独立调用，限制横轴
xlabel('时间 / ms'); ylabel('电压 / V');
legend('输入电压', '重建电压'); grid on;
```

- `stem`用竖线和标记展示离散样本，`'filled'`表示实心标记。
- 8 kHz采样下，包含0～2 ms两端应取`1:17`：16个间隔对应17个样本。
- `result.vin`与普通变量`vin`不是同一个变量，创建字段不会自动创建同名普通变量。
- `r = analyze_adc(...)`后，函数内的`result.vin`通过外部的`r.vin`读取。
- 本次脚本中的局部函数放在文件末尾，测试与绘图语句放在其前面。

## 3. 采样与混叠

### 3.1 预测与验证

| 输入频率 | 采样率 | 单边频谱峰值 | 现象 |
|---:|---:|---:|---|
| 7 kHz | 8 kHz | 1 kHz | 混叠 |
| 7 kHz | 10 kHz | 3 kHz | 混叠 |
| 7 kHz | 16 kHz | 7 kHz | 无混叠 |
| 6.5 kHz | 8 kHz | 1.5 kHz | 已实测验证 |
| 6.5 kHz | 10 kHz | 3.5 kHz | 已实测验证 |
| 6.5 kHz | 16 kHz | 6.5 kHz | 已实测验证 |

6.5 kHz测试三组峰值幅度均约为1。理想单正弦混叠可改变观测频率，而不降低幅值。

对于`fs/2 < fin <= fs`，观测频率为`fs-fin`；该表达式不能覆盖任意高频输入。

**扩展公式（补练参考，尚未独立验证）：**

```matlab
alias_hz = abs(mod(fin + fs/2, fs) - fs/2);
```

例如9 kHz输入、8 kHz采样，折叠频率为1 kHz；当前学生函数的简单分支会得到−1 kHz，需后续修正。

### 3.2 核心结论

- 实值信号的单边频谱通常显示0～`fs/2`；输入超过该范围时可能混叠。
- 在8 kHz采样下，零初相位的1 kHz与7 kHz正弦采样序列互为相反数；将7 kHz初相位改为`pi`后可与1 kHz序列重合。
- 仅凭1.5 kHz频谱峰，不能确定原始输入就是1.5 kHz。
- 混叠后，6.5 kHz输入可能与1.5 kHz输入产生相同样本。FFT显示1.5 kHz是正确分析采样数据的结果。
- 截止频率2 kHz的数字低通会保留该1.5 kHz分量；降低截止频率也无法将它与真正的1.5 kHz有用信号区分。
- 应在采样前限制模拟输入带宽，或提高实际采样率并匹配输入带宽。
- 采样点之间的绘图连线不代表原始连续波形。

## 4. 偏置、削顶与量化

### 4.1 偏置与幅值

以下均指量化前输入，且本次采样点包含正弦峰谷。

| 输入表达式 | 均值/DC | 正弦幅值 | 最小值 | 最大值 | 峰峰值 |
|---|---:|---:|---:|---:|---:|
| `1.65 + 1.0*x1` | 1.65 V | 1 V | 0.65 V | 2.65 V | 2 V |
| `1.20 + 1.0*x1` | 1.20 V | 1 V | 0.20 V | 2.20 V | 2 V |
| `1.20 + 0.6*x1` | 1.20 V | 0.6 V | 0.60 V | 1.80 V | 1.2 V |

改变偏置会平移波形并改变0 Hz直流分量；正弦幅值不随之改变。最大电压降低不等于交流幅值降低。

### 4.2 限幅与越界

```matlab
limited = min(max(vin,0),vref);
clipped_count = nnz(vin < 0 | vin > vref);
```

- `max(vin,0)`逐元素限制下端，`min(...,vref)`逐元素限制上端。
- `|`为逐元素逻辑“或”，`nnz`统计逻辑结果为真的点数。
- 恰好等于0或`vref`不算越界。
- 输入`1.65 + 2.0*x1`范围为−0.35～3.65 V，限幅后为0～3.3 V，两端削顶。
- 该限幅模拟输出饱和，不代表真实ADC引脚可以安全承受越界电压。

### 4.3 量化与误差

本实验采用端点映射模型：

```matlab
codes = uint16(round(limited/vref*(2^bits-1)));
vq = double(codes)*vref/(2^bits-1);
quant_rms = sqrt(mean((vq-limited).^2));
total_rms = sqrt(mean((vq-vin).^2));
```

相邻重建电压间隔为`vref/(2^bits-1)`。这是本次软件模型的定义，实际ADC的LSB与转换特性应按器件规格解释。

| 指标 | 比较对象 | 含义 |
|---|---|---|
| 量化RMS误差 | `vq`与`limited` | 限幅后电压映射为离散等级的误差 |
| 总RMS误差 | `vq`与`vin` | 削顶及量化共同造成的误差 |

无越界时两种误差相等；过幅时总误差通常更大。越界0点不代表量化误差为0。

4位、3.3 V模型的计算练习：

```matlab
limited = [0, 0.10, 0.12, 1.20, 3.30];
codes   = [0, 0,    1,    5,    15];
vq      = [0, 0,    0.22, 1.10, 3.30];
```

| 12 | 0.000806 | 0.000262 | 0 |

## 5. 独立代码练习与结果

接口：`result = analyze_adc(fin, fs, N, A, bias, bits, vref)`，正弦初相位固定为0。

要求：返回时间、输入电压、ADC码、重建电压、预测频率、输入均值/峰峰值、越界点数及两种RMS误差；完成三组测试，并叠加绘制前3 ms输入与重建电压。

| 组别 | fin/Hz | fs/Hz | N | A/V | 偏置/V | 位数 | vref/V |
|---|---:|---:|---:|---:|---:|---:|---:|
| 正常输入 | 1000 | 8000 | 256 | 1 | 1.65 | 12 | 3.3 |
| 混叠与粗量化 | 6500 | 8000 | 256 | 1 | 1.65 | 4 | 3.3 |
| 过幅输入 | 1000 | 8000 | 256 | 2 | 1.65 | 12 | 3.3 |

| 组别 | 预测观测频率/Hz | 均值/V | 输入峰峰值/V | 越界点数 | 量化RMS/V | 总RMS/V |
|---|---:|---:|---:|---:|---:|---:|
| 正常输入 | 1000 | 1.65 | 2 | 0 | 0.0002616 | 0.0002616 |
| 混叠与粗量化 | 1500 | 1.65 | 2 | 0 | 约0.0656 | 约0.0656 |
| 过幅输入 | 1000 | 1.65 | 4 | 64 | 约0.0003 | 约0.1750 |

第二组量化误差与1 kHz的4位测试不同，因为采样电压与量化等级的距离不同。第三组输入峰峰值仍为4 V；限幅后峰峰值为3.3 V。

绘图验证：正常输入两条曲线几乎重合；4位量化偏差明显；过幅输入在0和3.3 V处削顶。

代码保存在同目录的`worl1.m`；原始实验脚本位于`../实验1/experiment1.m`。当前学生函数的混叠预测适用于`0 <= fin <= fs`，未覆盖任意输入频率。

## 6. 问答与纠错摘要

| 问题 | 我的回答/初始问题 | 结论或修正 |
|---|---|---|
| 如何计算RMS？ | 最初写`sqrt(x.^2)` | 这是逐元素绝对值；应先平方、求平均，再开平方 |
| 如何计算交流RMS？ | 最初在平方后减均值 | 应先去均值，再计算RMS |
| 每隔一个取样仍按8 kHz解释？ | 1 kHz被解释为2 kHz | 正确，时间轴缩短一半 |
| 0～2 ms包含多少样本？ | 最初回答16 | 应为17：16个间隔、17个样本 |
| 偏置降低，1 kHz幅值是否降低？ | 最初认为降低 | 只改变DC；正弦幅值与峰峰值不变 |
| `max(v,0)`的结果是什么？ | 最初只写边界0 | 返回逐元素比较后的完整数组 |
| 越界0点是否表示无量化误差？ | 不表示 | 正确，范围内电压仍可能无法精确表示 |
| 为什么过幅总误差更大？ | 重建点不能恢复越界原始点 | 正确，总误差包含削顶影响 |

代码纠错要点：`t`必须是数组；使用`fin*t`；统一结构体字段引用；`if`与函数各自需要`end`；电压不能与整数码共用同一纵轴比较；绘图毫秒换算不能进入正弦相位计算。

### 正式问答（17/20）

1. **8 kHz采样观察1 kHz，10 kHz采样观察3 kHz，稳定单频输入在0～8 kHz：原频率？**
   - 回答：7 kHz，未展开过程。结论正确，3/5。
   - 完整依据：`8−7=1`、`10−7=3`，同时满足两次观测。
2. **1.5 kHz有用信号与6.5 kHz干扰，8 kHz采样后能否用数字低通分离？**
   - 回答：不能，提高采样率。4/5。
   - 补充：实际采样率应高于13 kHz，例如16 kHz；或采样前模拟滤波抑制干扰。
3. **`1.0+0.8*x1`的指标，以及偏置改为0.5后的变化？**
   - 回答：原均值1 V、峰峰值1.6 V、不越界；改后均值0.5 V、输入峰峰值不变、削顶。5/5。
   - 改后输入范围−0.3～1.3 V，下端削顶。
4. **20个样本为4095码，是否证明20个输入超过3.3 V？**
   - 回答：不能，可能是满量程；用示波器检查。5/5。
   - 满量程码可由范围内接近上端的输入产生，不能等同于越界计数。
