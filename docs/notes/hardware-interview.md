## 电荷部分

信号传递方向：

信号源 ---> 传输线 --->运放（负载） PS: 运放的输入阻抗  >>  信号源输入阻抗 也就是负载不能过重

对于高源阻抗：Rs(内阻)在MΩ级别，需要选择JEFT/CMOS工艺，Ib（偏置电流）比较小的 确保运放几乎不从前级吸收任何电流  

对于低源阻抗：Rs(内阻)在50欧左右，需要选择BTJ运放，运放的输入阻抗不需要太高，需要追求（Vos）最低输入电压噪声



总输入等效噪声 ≈ sqrt(en² + (in × Rs)² + 4kTRs)

`en`：运放输入电压噪声，单位 nV/√Hz；

`in`：运放输入电流噪声，单位 pA/√Hz 或 fA/√Hz；

`Rs`：信号源阻抗；

`4kTRs`：源电阻热噪声。

> 注意！偏置电流*输入电阻，才是最终的等效运放噪声
