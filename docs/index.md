# 学习手记

记录学习、实践与思考，让知识慢慢生长。

这里是一份持续更新的个人学习笔记。按主题整理知识，记录动手实践的过程，也保留那些值得回头再看的问题。

## 从这里开始

- [学习笔记](/notes/) — 把新知识整理成自己能理解的表达。
- [实践项目](/projects/) — 记录从想法到实现的过程。
- [问题记录](/troubleshooting/) — 留下问题、原因和解决方法。

## 第一篇笔记

本站附带一篇 [Markdown 入门](/notes/markdown)示例，可以边看边尝试。准备写自己的内容时，参考[写作指南](/guide/writing)。

::: tip 写给未来的自己
不必等到完全掌握才开始记录。一段解释、一个例子、一个问题，都可以成为一篇笔记的起点。
:::
